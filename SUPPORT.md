# Getting help: TypeSafeAI Community

> **Unofficial community organization, not the official TypeSafe AI team.**

## Community projects

For help with a project in this organization:

1. Read the repository's README. It covers setup, required tools, optional API-key configuration, and known limitations. Many projects run offline or in demo mode first.
2. Search the repository's existing issues and discussions.
3. Open an issue in that repository with the exact steps, versions, and what you expected. Use synthetic data and never paste API keys.

[`typesafe-playground`](https://github.com/TypeSafeAI/typesafe-playground) uses [Discussions](https://github.com/TypeSafeAI/typesafe-playground/discussions) instead of issues; [`jev-harness`](https://github.com/TypeSafeAI/jev-harness/discussions) has Discussions too.

## Official TypeSafe AI product support

Questions about the TypeSafe AI API, Jev, official SDKs, accounts, billing, or rate limits belong with the official team. Community maintainers cannot help with them.

- [TypeSafe AI website](https://typesafe.ai)
- [Official documentation](https://docs.typesafe.ai)
- [Official GitHub organization](https://github.com/typesafe-ai)

## Security

Do not report vulnerabilities in public. Follow [SECURITY.md](SECURITY.md).

## What to expect

Community projects are maintained by volunteers, with no guaranteed response time or service level.
