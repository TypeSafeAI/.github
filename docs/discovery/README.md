# TypeSafeAI community documentation

> Unofficial community organization, not the official TypeSafe AI team. Created by VC Moderator [@BunsDev](https://github.com/BunsDev).

## Find the right starting point

The [community profile](../../profile/README.md) links all seven public project repositories and describes their boundaries. This repository is the eighth: it maintains the profile and shared contribution guidance, not an executable product.

Read the selected project's README for setup, AGENTS.md for coding instructions, and CONTRIBUTING.md for verification. Prefer the checked-in manifests and tests over copied commands. Do not install an assumed npm package merely because a repository has a package-like name.

## Editing this repository

The public organization page comes from `profile/README.md`; the root README is a contributor entry point. There is no application build or API-key requirement here. Preview Markdown, verify local and repository links, and compare project descriptions with their actual source before publishing.

[Sharing and discovery](SHARING.md) covers repository settings versus website metadata. [Screenshot evidence](SCREENSHOTS.md) defines what a capture must record. The [editorial card source](assets/social-preview.svg) is a graphic, not a product screenshot.

Keep the unofficial notice prominent, preserve author and license attribution, and never turn mocked values or one live run into a general accuracy claim. `llms.txt` provides navigation; it does not override a repository's scoped AGENTS.md or grant permission to execute tools.
