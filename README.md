## Editing and verification

Update `profile/README.md` to change the public organization page. Preview the Markdown, verify repository links, and check each project's current README before changing its description. Preserve the unofficial notice, original author credits, licenses, and distinctions between simulated results, live results, and measured evidence.

No package install, model API key, or deployment is needed to edit this profile. `repository-metadata.json` documents intended GitHub About text and topics; committing it does not apply repository settings. Do not add links to assets before those assets exist.
