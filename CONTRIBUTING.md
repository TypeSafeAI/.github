# Contributing to TypeSafeAI Community

> **Unofficial community project — not the official TypeSafe AI team.** Created by VC Moderator [@BunsDev](https://github.com/BunsDev).

Small documentation fixes, reproducible examples, accessibility improvements, and focused project contributions are welcome. Start in the relevant repository, read its README and AGENTS.md, and keep pull requests narrowly scoped.

Explain what changed and how it was verified. Preserve attribution and licensing. Never publish credentials or private data, and do not present mocked or simulated output as live provider evidence.
