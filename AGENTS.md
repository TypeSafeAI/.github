# Agent guide — TypeSafeAI Community

This is an unofficial community organization, not the official TypeSafe AI team. Read the README and relevant repository instructions before editing.

Preserve attribution, licenses, security boundaries, mock/live distinctions, and existing verification gates. Do not invent benchmark results, package availability, deployment URLs, passing checks, or production readiness. Use synthetic data for examples and screenshots. Repository topics are capability metadata, not ranking claims.

The community health files at the root (`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md`) are organization-wide defaults. A change here affects every repository without its own copy, so keep them generic. Validate issue forms with `ruby -ryaml -e 'ARGV.each { |f| YAML.load_file(f) }' ISSUE_TEMPLATE/*.yml`. Never weaken the private vulnerability-reporting instruction or the official-versus-community support split.
